PriceLog Ver.0.93

変更点：ラベル管理・商品一覧のラベル別タブ・商品登録時のラベル選択・ラベル一括設定・クラウド共有へのラベル同期。
- 設定 → ラベル管理から追加、名称変更、並び替え、削除。
- 商品追加/商品設定にラベル欄。既存の商品はそのまま。新規商品には前回使用したラベルを初期表示。
- 一覧は「すべて」「使用中のラベル」「未分類」を表示。検索は選択タブ内。
- ラベル一括設定で複数商品に分類。
- 旧バックアップから読み込み可能。新バックアップと共有データにはラベル情報を含む。
- クラウド保存対象に商品とラベルを含む。SQL変更不要。

インストール：ZIPを解凍し、GitHub PriceLogのmain直下へファイルをアップロード（フォルダの中身を配置）。
共有中の各端末をVer.0.93へ更新してください。更新前にJSONバックアップを保存することをおすすめします。
