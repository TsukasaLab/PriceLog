PriceLog Ver.0.86

価格比較を素早く記録するPWA。

主な機能
- 商品一覧 / 買い物メモ / 売り場比較
- 1件追加 / 同じ店舗をまとめて追加
- 商品名比較 / 種類比較
- 登録済み候補・表記揺れ吸収・重複時の上書き確認
- 単位候補の拡充と自由入力
- 入力中のキーボード表示を維持したスクロール
- バックアップ / 差分共有ファイル
- Googleログインによるクラウド保存
- 自分専用データ / 共有グループの切替
- 共有データのリアルタイム同期

Ver.0.86 変更
- スマホのアカウントボタン位置を調整
- Googleプロフィール画像取得を強化。画像が無い時はログイン中アカウントの頭文字を表示
- 商品コード検索機能と関連設定・保存処理を完全撤去
- 商品テンプレート機能と関連ファイル・保存処理を撤去
- はじめに・使い方を初心者向けに全面刷新
- ボタン状態を統一。現在選択中は緑、未選択・操作待ちは白

既存のローカル商品データ、クラウドデータ、バックアップ形式は可能な範囲で互換維持。旧データに廃止済み項目が含まれていても読み込み時に無視する。
