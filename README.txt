PriceLog Ver.0.91

Ver.0.90をベースに「商品名」と「種類比較」の同名商品を手動で結合する機能を追加。

- 異なる登録方式で名称が一致する商品を薄赤色で表示
- 商品詳細の「データを結合」から種類比較へ統合
- 同じ店舗でも商品情報・内容量が異なる場合は別々に保持
- 同一商品の可能性がある競合は、両方残す/商品名側を採用/種類比較側を採用から選択
- 完全一致の行だけ自動重複除去
- 既存の価格変更履歴を保持し、由来も表示
- 直前の結合を、結合先が未変更の場合に限りこの端末から取り消し可能
- 買い物メモのチェック済み行を可能な限り保持
- 同店舗の複数行を商品詳細編集・売り場比較・クラウド結合で維持
- Googleクラウド利用時は結合直前に更新日時を照合

使い方：商品一覧で薄赤色の商品を開く → 「データを結合」 → 競合を確認 → 「確認して結合」。
結合を取り消す場合は結合後に「結合を元に戻す」、または設定内の同名ボタンを押してください。
端末保存の復元データは直前の結合1件分です。念のため実行前に設定からJSONバックアップを取ってください。

注意：共有クラウドの同時書き込みを完全に排他制御する機能は含まれません。
異なる端末から同時に同じ商品を編集しないでください。
ほかの改善ストック（通常価格/安売価格、単位換算、個別行登録など）は今回未実装です。
