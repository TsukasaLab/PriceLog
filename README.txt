PriceLog Ver.0.92

Ver.0.91からの変更：
- 商品詳細の店舗行の小見出しをなくし、空欄には「店舗」「商品情報」「量」「通常価格」「安売価格」と薄いプレースホルダーを表示
- 各欄の高さ・余白を統一してPC/スマホで崩れにくい配置に修正
- 税区分の表示を「税込」「税抜」の二文字に変更
- 店舗ごとに「通常価格」と「安売価格（任意）」を登録可能に変更。旧価格フィールドはそのまま通常価格として継続、安売価格フィールド salePrice を追加
- 通常・安売とも税込換算と単価を表示。商品一覧では通常最安と安売最安を確認可能
- 新規商品追加・まとめて追加・売り場比較の登録にも安売価格の入力欄を追加
- 買い物メモでは通常価格と安売価格のうち安い方を小計に採用
- 入力の値に「円」「g」などの文字を追加する旧処理を変更。数値の後ろの単位は表示装飾のみ
- 結合時の完全一致チェックにも安売価格を含めるため、価格が違う2件が勝手に重複除去されない

従来のバックアップ（schemaVersion 3）は引き続き読み込めます。Supabaseの表変更は不要です。
アプリ更新はGitHubへZIPを展開したファイルを上書きしてください。
旧バージョンで別端末が同じ共有データを保存すると安売価格フィールドを保持しない可能性があるため、共有メンバー全員をVer.0.92に更新することをおすすめします。
複数端末で同じ商品を同時編集する機能はまだ排他制御がありません。
